- **Shift scheduling for a 24/7 care facility.** The coordinators were happy with their paid tool, so the bar for switching was high. I wrote the spec from a recorded meeting with them and set the pilot's pass criteria before any code.
- **Audience messaging for a business-consulting firm.** Three audiences, a value message for each, and short videos to replace the firm's text messages.
- **Research tooling for a rare-disease nonprofit (Yad LeNeshima),** as a volunteer. A tagging layer for the research literature, built with the chief scientist, with results turned into decision decks over eight feedback rounds.
- **AI workshops since 2024,** for non-technical and developer audiences.
- **Quiz funnel for a free IQ test,** built against an ad-tech company's challenge brief. Positioned on trust: what is free is said up front and nothing is blurred. Three A/B test designs with decision rules and a measurement spec. A prototype; no live experiment was run.

Most of this work holds client or member data, so the repositories are private. I'm glad to walk through the specs and decisions in conversation.
